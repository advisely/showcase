# Quick Start Guide

## Get Started in 30 Seconds

```bash
# 1. Install dependencies
npm install

# 2. Start the app
npm run dev

# 3. Open your browser (auto-opens to http://localhost:3000)
```

That's it!

## First Steps

1. **Name Your Presentation** - Click the title field in toolbar to rename
2. **Add Media** - Click "Add Media" button
3. **Choose Orientation** - Select Landscape or Portrait
4. **Add Text** - Click "Expression" to add styled text
5. **Drag Elements** - Move cards and text around freely
6. **Try Layouts** - Click Circle, Curve, Grid, or Line buttons
7. **Create Groups** - Organize cards into Parts, Chapters, or Sections
8. **Customize** - Change background color or add background image

## Key Features

### Presentation Name
- Click the title field in the toolbar to rename
- Press **Enter** or click away to save
- Press **Escape** to cancel changes
- Name appears in exported filenames

### Fullscreen Mode
- Click the fullscreen button to enter presentation mode
- All buttons hidden except exit button
- Title centered in toolbar
- Perfect for presenting to audiences

### Drag & Drop
- **Drag to move** - Click and drag any card or text field
- **Resize** - Drag the bottom-right corner of cards
- **Click to view** - Click once to maximize cards

### Text & Typography
- **Add Text** - Click "Expression" button to add text
- **Edit Text** - Single-click text to edit content (type immediately)
- **Edit Properties** - Double-click text to change font, size, color
- **Font Choices** - 10+ fonts including Sans-serif, Serif, Monospace, Cursive
- **Size Options** - 16 preset sizes from 12px to 128px
- **Color Presets** - 20 quick-pick colors + custom color picker

### Groups & Organization
- **Create Groups** - Click "Groups" in Elements menu
- **Thumbnail View** - Collapsed groups show card thumbnails
- **Expand View** - Double-click to expand and see full cards
- **Navigate** - Use arrows in fullscreen to browse group cards

### Zoom & Pan
- **Zoom In/Out** - Use buttons on the left sidebar
- **Pan** - Click and drag the background
- **Refocus** - Click target icon to reset view

### Save & Load
- **Auto-Save** - Changes save automatically after 1 second
- **Export JSON** - Click Save button (all settings included)
- **Export ZIP** - Click Export (hybrid: images embedded, videos external)
- **Load** - Click Load and select a .json or .zip file
- **File Naming** - `showcase-name-YYYY-MM-DD-hh-mm-ss.json`

### Animation Settings
- **Card Speed** - Settings > Card Settings > Animation Speed
- **Group Speed** - Settings > Group Settings > Animation Speed
- Choose from Slow, Normal, Fast, or Very Fast

## Tips

**Pro Tip:** Name your presentation first - it becomes part of the filename when you save!

**Pro Tip:** Use Groups to organize large presentations into logical sections

**Pro Tip:** Use Fullscreen mode when presenting to hide all editing controls

**Pro Tip:** Export as ZIP for presentations with many videos (keeps file size small)

**Pro Tip:** Your work auto-saves to IndexedDB - no more "quota exceeded" errors!

## Troubleshooting

### Port Already in Use?
If you see "Port 3000 is in use", the app will use the next available port automatically. Check the terminal for the actual URL.

### Can't See Changes?
Hard refresh your browser: `Ctrl + Shift + R` (Windows/Linux) or `Cmd + Shift + R` (Mac)

### Need Help?
Check the browser console (F12) for error messages.
